【C Role 角色】
你是精通 Python tkinter、拖拽 GUI、JSON 持久化、Windows 文件树、图片加载预览、剪贴板操作的开发工程师，擅长模块化解耦拆分多个 py 文件，能处理图片显示、缩放、排版，控制台输出详细调试日志，代码可以直接在 PyCharm 运行，严格修复历史全部 bug。

【R Context 背景】
原有项目是文字标签系统，现在改造为图片标签系统，保留原有全部交互框架、布局、拖拽、预设、分组、持久化、文件树逻辑；核心改动：标签不再是纯文本标签，而是绑定图片的标签；支持打开图片文件、预览图片。
原有完整规则、bug 清单、改进项、布局（左：Windows 文件树｜中：标签组 + 字符串生成｜右：标签仓库）全部继承，不再删减原有功能，只叠加图片相关能力。

原有继承规则摘要：
窗口最小 1200×800、可缩放最大化；布局三栏【文件树栏｜中间标签工作区｜右侧标签仓库栏】；5 组互斥预设，每个预设独立保存标签组，标签全局共享；数据保存到 tag_data.json，启动自动加载；标签组拖拽排序、标签组内标签点击选中  取消选中、右键删除、拖拽到右侧删除；选中标签按组从上到下、组内从左到右拼接，下划线连接，末尾追加 yyyyMMddhhmm 时间；一键命名按钮对文件树选中文件做 Windows 系统真实重命名、重命名不收起目录展开状态；文件排序规则：重命名文件放末尾、带 () 数字按数值从小到大排序；控制台打印调试信息。
历史已知 bug 必须全部修复：标签选中立刻更新拼接串、标签组支持拖拽排序、预设互相独立互不干扰、启动加载 json 数据、预设互斥单选、拖拽跨组时源组移除标签。

【I Instruction 指令】
基于原有文字标签程序，改造为图片标签系统，新增图片相关需求，原有所有功能保留不变：

1. 文件树（最左侧）：支持选中图片格式文件（jpgpngjpegbmpgifwebp）；选中图片文件后，可以点击按钮【新建图片标签】，把这张图片生成标签存入右侧标签仓库。
2. 标签主体：标签不再只有文字；每个标签绑定一张图片 + 可选备注文字。
   - 标签视觉：椭圆圆角，内部展示缩略图，缩略图下方展示简短备注文字；标签大小自适应图片缩略图 + 文字，四周预留 padding 5px。
   - 右侧标签仓库：图片标签横向自动换行、纵向滚动；标签缩略图做等比例压缩，防止过大撑破布局；图片过大时自动生成缩略缓存，不要原图超大渲染。
3. 图片预览：
   - 双击任意图片标签（右侧仓库、中间标签组内），弹出独立预览窗口，原图自适应缩放，支持滚轮缩放图片、拖动平移图片，可关闭预览窗口。
4. 导入入口补充：
   - 右侧顶部除原有文本输入框、保存、清空按钮外，增加【选择图片】按钮；点击唤起 Windows 文件选择框，选中图片后自动生成图片标签，备注文本可在输入框填写。
5. 标签数据持久化改动：JSON 保存标签时，保存图片文件绝对路径、备注文字；不把图片 base64 塞进 json（只存路径）；加载时根据路径读取图片；图片丢失时标签显示占位图 + 提示【图片不存在】。
6. 拼接字符串规则修改：
   - 拼接内容优先使用标签备注文字；备注为空时，自动取图片文件名（不含后缀）；其余拼接逻辑完全不变：组顺序从上到下、组内选中标签从左到右、下划线分隔、末尾追加 yyyyMMddhhmm 时间戳。
7. 拖拽规则继承：
   - 右侧图片标签可以拖入中间任意标签组；组内图片标签点击切换选中  取消选中（亮色标记选中）；图片标签跨组拖拽时，源组移除该标签；拖拽回右侧仓库 = 删除；右键标签弹出删除菜单。
8. 文件树逻辑不变：依然支持所有磁盘、文件夹双击展开，图片文件可选中；一键命名依然修改 Windows 真实文件名；重命名后图片标签内部记录的文件路径自动同步更新，避免路径失效。
9. 模块化解耦：继续分文件拆分，例如 `main.py`、`file_tree.py`、`image_tag.py`、`tag_group.py`、`preset_manager.py`、`data_store.py`；不要全部堆在单文件。
10. 控制台日志：图片加载、图片缺失、标签选中变更、预设切换、文件重命名、拖拽事件全部打印日志，方便调试。
11. 样式继承：系统功能文字加粗加大清晰；标签内图片 + 备注文字字体更小；标签组自动换行排版规则和原来一致。

【S Output Format 输出格式】
输出全部 py 源码文件，每个文件分开标注文件名；附带启动说明、依赖清单；代码注释清晰；优先保证可以直接在 PyCharm 运行；输出前说明新增功能点清单。
